# True North Trivia (The Great Canadian AI Trivia)

**The intelligent trivia experience that actually speaks our language.**

True North Trivia is a premium, AI-powered trivia platform designed specifically for the Canadian audience (18-50). It solves the frustration of "US-Defaultism" in standard quiz apps by offering a curated mix of hyper-local Nostalgia, globally balanced General Knowledge, and real-time Pop Culture trends.

## 🍁 Core Vision & Unique Value Proposition

**1. Culturally Relevant (Anti-US-Defaultism)**
We avoid questions about obscure American senators or US state laws. Instead, we feature the "Global, Eh?" pillar—general knowledge that is globally relevant or specifically Canadian.

**2. AI-Powered Freshness**
Unlike static trivia decks, our **AI Content Engine** ingests daily news signals (RSS/API) to generate "Fresh Prints" questions. If it happened this morning, you might see it in tonight's game.

**3. Themes on Demand**
Players can request niche custom themes (e.g., "1990s Toronto Raves" or "Organic Chemistry") and the AI will generate unique rounds on the fly.

## 🎮 Game Modes

### 1. Team Mode (The Social Default)
*   **Mechanic: "The Polite Interrogation"**
*   **Rule:** No passing allowed. Teams *must* answer, even if they have to invent a creative lie. Opposing teams can steal points by calling "Bullsh*t".
*   **Best For:** Party play and social friction.

### 2. Classic Mode
*   **Mechanic:** Standard Pub Quiz.
*   **Best For:** General Knowledge and "Global, Eh?" content.

### 3. Blitz Mode
*   **Mechanic:** Rapid-fire, timed rounds.
*   **Best For:** High-volume current events and viral trends.

## 🧠 The Content Mix

Our content strategy is built on four columns:

*   **The Time Capsule (30%):** Gen X / Millennial nostalgia (Degrassi, MuchMusic, House Hippos).
*   **Global, Eh? (30%):** Smart, non-US-centric general knowledge (Science, History, Lit).
*   **Fresh Prints (25%):** Viral trends and pop culture from the last 3 months.
*   **The Great Outdoors (15%):** Culinary, travel, slang, and cottage life.

## 🚀 Getting Started

To deploy True North Trivia locally:

1.  Clone the repository:
    ```bash
    git clone https://github.com/sfigas01/Trivia-Game-Antigravity.git
    cd Trivia-Game-Antigravity
    ```

2.  Install dependencies:
    ```bash
    npm install
    # or
    yarn install
    ```

3.  Launch the development grid:
    ```bash
    npm run dev
    ```

4.  Access the terminal at [http://localhost:3000](http://localhost:3000).
