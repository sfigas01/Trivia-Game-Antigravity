# The Arena - Global Trivia

**Welcome to The Arena.**

This is not just another trivia game. It is a competitive intellectual battleground where teams clash for supremacy. Select your region, assemble your squad, and prove your knowledge in a high-stakes environment.

## Key Features

### 🌍 Region-Specific Intel
Start your campaign by selecting a strategic region (e.g., US, UK, Japan, Brazil). Your choice sets the stage for the battle to come.

### ⚔️ Multi-Team Combat
Support for **2 to 6 teams**. Whether it's a duel or a free-for-all, The Arena handles the chaos.
-   **Dynamic Roster**: Add or remove teams on the fly during setup.
-   **Custom Call Signs**: Name your teams to strike fear (or confusion) into your opponents.

### 🧠 Dynamic Intelligence
Questions aren't static. They are pulled in real-time from the **Open Trivia Database**, ensuring a fresh challenge every round.
-   **Focus Areas**: Geography, History, and Politics.
-   **Live Updates**: Never memorize a card again.

### ⚡ Live Scouting & Scoring
Real-time score tracking with visual feedback.
-   **Gain Ground**: Correct answers boost your standing (+1).
-   **Penalty**: Failure has consequences (-1).
-   **Visuals**: Sleek, glassmorphism-inspired UI with smooth animations and dynamic lighting effects.

## Tech Stack

Built with modern web technologies for performance and aesthetics:
-   **[Next.js](https://nextjs.org/)**: The React Framework for the Web.
-   **React Hooks**: Complex state management for game phases.
-   **CSS Modules**: Custom, component-scoped styling.
-   **Glassmorphism**: Premium visual design with translucent layers and gradients.

## Getting Started

To deploy The Arena locally:

1.  Clone the repository:
    ```bash
    git clone https://github.com/sfigas01/Trivia-Game-Antigravity.git
    cd Trivia-Game-Antigravity
    ```

2.  Install dependencies:
    ```bash
    npm install
    # or
    yarn install
    ```

3.  Launch the development grid:
    ```bash
    npm run dev
    ```

4.  Access the terminal at [http://localhost:3000](http://localhost:3000).
